# Full-Stack MERN Task Manager Application — MERN Week 3 Project

## 📌 Project Overview
This repository contains the **MERN Stack Week 3 Mini Project**[cite: 69]. It is a full-stack **Task Manager Application** featuring user authentication (JWT), task creation, status updates, deletion, and filtering[cite: 69].

---

## 🛠️ Architecture & Tech Stack[cite: 69]
* **Frontend**: React (Vite), Axios, State Management (`useState`, `useEffect`)[cite: 44, 69].
* **Backend**: Express.js, Node.js, Bcryptjs, JWT Authentication[cite: 58, 69].
* **Database**: MongoDB & Mongoose ORM[cite: 58, 69].

---

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone [https://github.com/mahima5080/MERN-Task-Manager-App.git](https://github.com/mahima5080/MERN-Task-Manager-App.git)
   cd MERN-Task-Manager-App

1. Start Backend:
cd backend
npm install
npm run dev

2. Start Frontend:
cd ../frontend
npm install
npm run dev
